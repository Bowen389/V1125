# S 级六策略每日盘后预选 & 09:31 开盘筛选工作包

- [最新盘后预选报告](reports/latest.md) · [最新 09:31 开盘筛选报告](reports/opening/latest.md) · [GitHub Actions 定时任务](.github/workflows/daily.yml)

本仓库基于对 `top`、`DCEGHABF`、`2j3` 三个原始工作包在 2021-08 ~ 2026-11 本机通达信全市场日线（5,586 只 A 股）上的回测验证与底层重构，保留通过严格 IS/OOS 检验的 **S 级全部 6 条新一代策略**，每日自动生成盘后候选与次日开盘竞价筛选结果。

- **定时调度（北京时间，周一至周五）**：`17:00` 盘后首扫、`17:30` 盘后补扫、`09:31` 竞价缺口筛选；支持 Actions 手动触发。
- **回测统一口径**：**不复利固定本金单利 MTM + 现实成本**（买佣万 2.5、卖佣万 2.5 + 印花税万 5 + 单边滑点 0.1%，严格 T+1、开盘涨停不买、跌停/停牌顺延）。

## 二、S 级六策略规则速查

1. **`2j3-Next`**：主板非 ST、非一字首板、20 日均额位居当日主板 **Top 5%**、首板换手 `≥ 6%`；零门控；次日高开 `[2%, 6%]` 按高开降序买；二板封住→T+2 开盘卖，未封→T+2 收盘卖（3 仓 × 33%，日限 2 只）。
2. **`Core-Rebound`**：主板非 ST、上市 ≥ 60 日、收盘 ≥ 3 元、20 日均额 `≥ 5亿`、`T-10..T-2` 恰 1 次涨停、`T-1` 收阴非炸、T 日非一字涨停且 `open ≥ 昨收`、换手 `< 20%`；按 20 日均额降序，次日缺口 `[-5%, +6%]` 买；T+2 起收盘涨停顺延最多 5 次（6 仓 × 16.7%，日限 2 只）。
3. **`LHB-Next`**：沪深 A 股非 ST（含双创）、沪深 300 `> MA20`、龙虎榜单日榜、首次上榜、非连板、机构总净买 `≥ 3000万`（允许卖方机构）；按净买额降序，次日缺口 `≥ -5%` 买；T+2 收盘卖、收盘涨停顺延最多 3 次（4 仓 × 25%，日限 2 只）。
4. **`FB-Next`**：中证 1000 `< MA20`、主板非 ST、非一字/T 字首板、成交额 `≥ 1亿`、换手 `≤ 10%`、收盘/VWAP 乖离 `≥ 1.5%`；C2（`pos60<0.70`, 缺口 `[-3%, +3%]`）优先、C1（`0.70~1.0`, `[-5%, -2%]`）其次，同档按缺口升序；T+2 收盘卖 + 收盘涨停顺延（6 仓 × 16.7%）。
5. **`CFGH-Next`**：上证 `≥ MA20` × 全 A 宽度 `≥ 55%` 分四象限，主板 20 日均额 `≥ 5000万`，统一缺口 `[-3%, 0%)`，收盘涨停顺延：Q1 突破池等权 `+上影-振幅` Top20%（持 2 日）；Q2 突破池等权 `+上影-5日动量` Top20%（持 1 日）；Q3 缩量守位池 `-VWAP乖离`（持 1 日）；Q4 空仓防守（单笔 10%，日限 2~3 只）。
6. **`V3-Next`**：沪深 300 `≥ MA20`、主板非 ST、20 日均额 `≥ 1亿`、收盘 ≥ 3 元、突破 60 日新高且振幅 `< 6%`；按 VWAP 乖离升序排；次日温和低开 `[-2%, -0.5%)` 买，持有 2 日收盘卖（5 仓 × 20%，日限 2 只）。

## 三、本地运行

```bash
pip install -r requirements.txt
python src/run.py                 # 盘后扫描（默认最近一个完整交易日）
python src/run.py --opening       # 09:31 开盘缺口筛选
```
